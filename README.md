# BT2 Fusion

> This project serves players of *Battle Teams 2* (生死狙击 2), Chinese mainland server only, global servers are not supported.
>
> 本项目只服务《生死狙击 2》（下文所称「热油」是该游戏的调侃别称）国服玩家，国际服和其他国家专服不在受支持之列。

简介：本项目是一个**聚合平台切换器 + 启动器**，可快捷切换热油的登录渠道，以及启动热油（免于在游戏菜单里找游戏）。

原理：热油国服除 WeGame、Steam 两个独立客户端外，其余渠道共用同一份游戏客户端，**启动时显示哪种登录方式，只看游戏目录下的两个配置文件**。本项目就是对多个渠道的配置文件进行封装，并通过可视化界面呈现，帮助技术小白玩家快速上手。

## 使用

1. 在装有热油的电脑上下载 `bt2fusion.exe`，双击运行；
2. 程序会自动检测热油安装目录，如果提示「未找到游戏」，点「选择目录」，选中**游戏根目录**（里面能看到 `WDlauncher.exe` 的那个文件夹）；
3. 「渠道切换」下拉框里显示的就是当前渠道（自动检测，一般不用管它）；
4. 在下拉框里选你要用的渠道；
5. 点「切换到」，等待该按钮置灰并显示「已是此渠道」；
6. 点「热油，启动！」开始游戏

## 支持的渠道

**官方、体验服、网吧、bilibili、4399、联想、斗鱼** —— 这七个渠道共用同一份客户端，换配置文件就能互相切换。

> 「网吧」渠道是**顺网、官服、易乐玩三合一**的入口，这三者在游戏启动器里就能直接切换；官服有独立配置也照常提供，彼此不冲突。

**WeGame 与 Steam 是独立客户端**，登录方式与上面这些渠道不互通，不在支持范围内。

## 主要适用人群

### 一、网吧玩家但主号非对应渠道

网吧的无盘系统（网维大师/顺网、云更新等）装好的客户端，带的是**网吧渠道**（**顺网、官服、易乐玩三合一**），这三个在游戏启动器里就能直接切换。还有 Wegame 一般也是默认装好的。如果你的其它受支持的渠道：bilibili、4399、联想、斗鱼…，那么本项目就是你的救星！那份几十个 GB 的游戏资源其实早就躺在硬盘里了，别傻乎乎地重下，也别将就重新开号，把本项目利用起来：

- 你的号在**顺网 / 官服 / 易乐玩** → 网吧客户端本来就能登，在启动器（微端）里换个入口就行，**用不上本项目**；
- 你的号在 **WeGame / Steam** → 这两个比较特立独行，**本项目也帮不上**，不过 Wegame 一般也是预装好的，可以自己先找找；
- 你的号在**其它受支持的渠道**（bilibili、4399、联想、斗鱼）→ 用 bt2fusion 切换：从「网吧」切换为你需要渠道。

> 如果你的号在顺网 / Wegame 其中一个，而网吧只装了另一个渠道的游戏，也别灰心，虽然本项目的构建产物对你来说没什么作用，但还是有邪修的：虽然其他渠道客户端（顺网、官网、4399、bilibili、斗鱼、联想）和 Wegame 游戏安装目录的结构不一样，而且对于不是自己渠道的文件严格排斥，但是可以确认的是 `assetbundleres/` 文件夹的数据是通用的——它就是那几十个 GB 的游戏资源所在，你只需要在更新游戏的那一步停住，关闭启动器，单独复制这个已有的这个文件夹去替换，再重启就行了。

### 二、接号代打的主播

主播常常要同时应付多个渠道的号,常见的做法是**在本地存一整套各渠道配置文件**，来一个号复制一份进游戏目录。

麻烦就出在「复制」这个动作上：

- **手一抖按成剪切（Ctrl+X）** —— 源文件被搬走了，自己的渠道库里少一份，而且**几乎察觉不到**，等下次真要切到那个渠道时才发现文件没了；
- 就算没按错，**反复翻目录、复制、覆盖**本身也够烦。

用下拉框切就简单了：**点两下换个渠道**。程序只读取内置的数据，不做任何移动操作，从根上避免了「把自己的库剪走」这种事。
